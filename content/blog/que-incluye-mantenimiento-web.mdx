## Qué incluye el mantenimiento web

El mantenimiento web incluye las tareas técnicas acordadas para conservar la web operativa: actualizaciones, copias de seguridad, revisiones y atención a incidencias. La frecuencia, los cambios de contenido y la recuperación ante fallos dependen del plan; hosting, dominio, rediseño y SEO continuo no se incluyen automáticamente.

Para comparar ofertas, pide una lista de tareas y condiciones. «Nos encargamos de todo» no explica qué ocurre si falla un formulario, se pierde contenido o necesitas una función nueva. Una empresa debe saber qué delega y qué sigue siendo responsabilidad propia.

## Las tareas que conviene revisar

### Actualizaciones y comprobaciones

En una web WordPress, el trabajo puede afectar al sistema, temas y plugins. En una aplicación a medida se revisan sus dependencias y componentes. No todas las webs necesitan las mismas tareas ni admiten la misma frecuencia de cambios.

Pregunta cómo se prepara una actualización y qué se comprueba después. La [documentación oficial de WordPress sobre actualizaciones](https://wordpress.org/documentation/article/updating-wordpress/) recomienda disponer de una copia antes de empezar. Para tu negocio, además interesa comprobar las funciones que utiliza el cliente: formulario, búsqueda, reserva o compra.

El servicio debe distinguir la actualización ordinaria de una incompatibilidad que requiera desarrollo adicional. Esa distinción evita aceptar como incluido un trabajo que después se presupuesta aparte.

### Copias de seguridad y recuperación

Pregunta qué se copia, dónde se guarda, con qué frecuencia y cuánto tiempo se conserva. En WordPress, una recuperación completa necesita archivos y base de datos, como explica su [manual oficial de copias de seguridad](https://developer.wordpress.org/advanced-administration/security/backup/).

La frecuencia debe corresponderse con lo que perderías entre dos copias. Una web corporativa con pocas modificaciones y una tienda con pedidos diarios tienen necesidades distintas. En una tienda, restaurar una copia antigua también puede afectar a información reciente; acuerda cómo se valorará ese riesgo antes de recuperar.

Pide que se concrete quién solicita la restauración, quién la ejecuta y si está incluida. Tener copias programadas y poder recuperar una web son tareas relacionadas, pero diferentes.

### Seguridad y revisión de errores

Un plan puede incluir medidas de acceso, escaneo y revisión de vulnerabilidades, según la tecnología. Solicita su alcance y qué sucede cuando aparece una incidencia: investigación, restauración, limpieza o presupuesto adicional.

También conviene revisar páginas relevantes, enlaces y funciones que pueden fallar aunque la portada siga visible. La monitorización de disponibilidad comprueba si la web responde; no demuestra por sí sola que se reciban los mensajes o funcionen los pagos.

## Cómo comparar planes de mantenimiento

Esta tabla sirve para pedir información, no como una cobertura universal. Cada proveedor debe confirmar qué tareas puede asumir en tu web.

| Aspecto | Información que necesitas | Por qué influye en la elección |
|---|---|---|
| Actualizaciones | Qué se actualiza y con qué frecuencia | Define el cuidado técnico periódico |
| Copias | Contenido, frecuencia, retención y ubicación | Permite valorar la pérdida posible de información |
| Recuperación | Procedimiento, condiciones y coste | Aclara qué ocurre ante un fallo |
| Soporte | Canales, horario y prioridad | Evita confundir monitorización con atención humana |
| Contenido | Horas, tipos de cambios y acumulación | Delimita las tareas que puedes solicitar |
| Exclusiones | Desarrollo, licencias y problemas previos | Hace comparable el precio mensual |
| Seguimiento | Registro de tareas o información disponible | Permite comprobar el trabajo realizado |

### Atención, respuesta y resolución

Pregunta por separado cuándo recibirás una respuesta y cómo se gestionará la resolución. Contestar a una solicitud no significa que la incidencia quede resuelta: puede depender del hosting, de una integración o de accesos que falten.

Si una oferta menciona monitorización las 24 horas, confirma el horario de atención de personas. También quién tiene acceso para actuar y cómo se priorizan problemas que impiden vender frente a cambios ordinarios de contenido.

## Qué suele contratarse por separado

El mantenimiento no equivale a disponer de horas ilimitadas de desarrollo. Conviene separar:

- **Hosting y dominio:** alojamiento, registro y renovaciones, salvo que estén incluidos expresamente.
- **Nuevas funciones:** reservas, integraciones o áreas privadas con alcance propio.
- **Rediseño:** cambios amplios de estructura o identidad visual.
- **Contenido nuevo:** redacción, fotografía y producción de artículos.
- **SEO continuo:** investigación de consultas, estrategia, contenidos y seguimiento comercial.
- **Problemas anteriores:** limpieza o puesta a punto necesaria antes de asumir la web.

Si buscas alojamiento además del cuidado técnico, consulta las condiciones del [hosting gestionado](/servicios/hosting). Si lo que necesitas es mejorar la captación desde Google, compara por separado el [servicio de posicionamiento SEO](/servicios/seo).

## Checklist antes de delegar tu web

Prepara la dirección de la web, tecnología si la conoces, accesos disponibles y una lista de incidencias. Después comprueba:

1. Qué tareas y frecuencias quedan acordadas.
2. Si hay problemas previos que resolver por separado.
3. Qué copias existen y cómo se recuperaría la web.
4. Canales, horario y prioridad del soporte.
5. Horas de contenido y tratamiento de tareas adicionales.
6. Costes externos, impuestos y condiciones de cancelación.
7. Qué información conservarás si cambias de proveedor.
